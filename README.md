📚 Library Management System
DBMS Mini Project

A Library Management System developed using MySQL Workbench as part of a Database Management System (DBMS) mini project.

📌 Project Overview

This project is designed to manage library operations, including student information, book details, book issuing, and book returning.

It helps maintain organized library records and track book availability using SQL queries.

🎯 Objectives
Manage student information.
Store book details.
Maintain book issue records.
Track book returns.
Display available books.
Demonstrate database relationships and SQL operations.

▶️ How to Run the Project
Install MySQL Workbench.
Open MySQL Workbench and connect to your MySQL server.
Download the LibraryDB.sql file from this repository.
Open the SQL file in MySQL Workbench.
Execute the SQL statements in the correct order.
Run the SELECT queries to view database records and results.

Note: The script creates the database and sample records. Running it again on an existing database may require resetting the database first.
